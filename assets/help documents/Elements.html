The Four Elements

Long ago, the four elements lived together in harmony. Then, everything changed when the objects attacked
Each element controls an individual aspect of a shape, getting bigger the further you go

Vertex

The smallest element, controlling only a point.
Vertices can be translated, tesselated, beveled,
Clicking the first element icon, or the '1' key, lets you select specific vertices.

Edge

Slightly bigger, edges link two vertices together.
Edges can be translated, scaled, extruded, tesselated, flipped, beveled,
Clicking the second element icon, or the '2' key, lets you select specific edges.

Face

Flat surfaces that span between edges, these comprise much of the shape.
Faces can be translated, scaled, extruded, tesselated, triangulated, beveled,
Clicking the third element icon, or the '3' key, lets you select specific faces.

Object

The whole shape. Encompasses all the faces, edges, and vertices contained within.
Objects can be translated, scaled, rotated, extruded, subdivided, tesselated, triangulated, beveled,
Clicking on the last element icon, or the '4' key, lets you select entire objects. This is the default.
