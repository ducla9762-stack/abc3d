Loop Cut

Splits a strip of faces with new edges that run alongside the edge you pick.

  • Hover an edge to preview the cut. Click to cut.
  • + / - changes how many evenly spaced cuts are made.
  • Esc leaves the tool.
  • Shortcut: L

The strip leaves each face through the edge halfway around it, so it runs through quads (and other faces with an even number of sides). It stops at an open boundary, at a face with an odd number of sides such as a triangle, or when it comes back to where it started. Faces where it stops get the new vertex on their side but are not split.
