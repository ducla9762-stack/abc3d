Selection

No matter the mode, double clicking the mouse deselects everything.

Classic Mode

When an element is selected, this mode will change the selection to the new element and deselect the old. That is, unless you hold Control, which will add to your selection

Additive Mode

When an element is selected, this mode automatically adds it to the current selection

Element Select

Each of the bottom left buttons allows for the selection of different parts of a shape.
The first button is for vertices, the second for edges, the third for faces, and the last for objects
Changing the active element also deselects
